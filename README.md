# Mehmet Aydın

Personal portfolio of a computer engineer and full stack developer. The site introduces the work, selected projects, and contact details in a single page.

**Stack:** React Native, React, Node.js, Laravel

## Preview

Open [`index.html`](index.html) in a browser, or serve the folder locally so fonts and scripts load correctly:

```bash
python -m http.server 5501
```

Then visit [http://127.0.0.1:5501/index.html](http://127.0.0.1:5501/index.html).

VS Code Live Server is set to port `5501`.

## On the page

- **Home** — name, role, and a short introduction
- **About** — how projects move from discovery to a shipped product
- **Work** — selected apps, logos, and web applications
- **Contact** — email and social links
